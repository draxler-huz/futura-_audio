# Why Driving Mode Uses a User Agreement

Driving Mode is a design choice to reduce distraction, not a complete safety solution. The app shows only play, pause, skip, and dismiss controls in large buttons, and users must accept an agreement before turning the mode on. We chose an agreement rather than automatic speed detection because speed or motion detection would require location or activity permissions, would not reliably tell a passenger from a driver, and could still fail in traffic or on public transport. Responsibility for safe use stays with the user, who is informed of the rules before the mode is enabled. The dismiss button remains visible at all times, so the user always has a way to close the overlay. We considered speed-based restrictions and noted them as a future improvement.
